📈 Similarity Analysis Reports

Select an assignment and click Check Similarity to compare its submitted PDFs.

The system compares each readable PDF with the other submitted PDFs belonging to the same assignment.

Automatic checking is performed when the teacher opens this dashboard after an assignment's end date. Manual checking is also available at any time.

Similarity percentage indicates textual overlap. It is not, by itself, proof of plagiarism.
